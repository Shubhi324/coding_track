# coding_track
# 📊 Coding Progress Tracker

This project visualizes your daily coding practice across multiple platforms (GFG, A2Z, Hackerrank) using a simple Python script and Matplotlib.

## 🗂️ Project Overview

The script reads a CSV file (`coding_track.csv`) containing the number of questions solved per platform for each date, and generates a clear, colorful line graph showing your progress.
